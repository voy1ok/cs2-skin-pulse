# CS2 Spread

Сайт, который сравнивает цены скинов CS2 на маркетплейсах и показывает топ предметов с самой большой разницей в цене между площадками.

- **Площадки:** Skinport, Waxpeer, LIS-SKINS — цены снимаются при каждом обновлении; Buff163, CSFloat, Youpin898 — по сводке [csgotrader.app](https://csgotrader.app), она обновляется раз в сутки. Market.CSGO — напрямую, а если площадка не пускает (с серверов GitHub отвечает 403), то тоже из сводки.
- **Что сравнивается:** минимальная цена лота на каждой площадке. У Buff163 и CSFloat есть ещё лучшая автопокупка (buy order) — по ней работает сортировка «Мгновенная продажа».
- **Обновление:** раз в 10 часов, GitHub Actions → GitHub Pages. Сервер не нужен.
- Все предметы, которые продаются в CS2: оружие, ножи, перчатки, наклейки, кейсы, агенты, брелоки, граффити и т. д. Картинки — [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API).

## Как считается разница

1. Площадка с числом лотов меньше 2 не учитывается (если число лотов известно).
2. Цена дальше чем в 2 раза от медианы по площадкам считается выбросом — обычно это устаревшая сводка или единственный лот по случайной цене.
3. Разница = (самая высокая цена − самая низкая) / самая низкая. Комиссии площадок не вычитаются.
4. Ножи с фазами Doppler не сравниваются: у всех фаз одно название на рынке, а стоят они в разы по-разному.

На сайте можно выбрать тип предмета, минимальную цену, минимальное число площадок и отключить отдельные площадки.

## Запуск локально

```bash
node scripts/collect.mjs   # собрать цены в site/data (≈10 секунд)
npx serve site             # открыть сайт
```

## Устройство

```
.github/workflows/update.yml  — раз в час проверяет, прошло ли 10 часов; если да — собирает цены и публикует сайт
scripts/collect.mjs           — опрос площадок → site/data/items.json, images.json, meta.json
site/                         — статический сайт без сборки (index.html, app.js, style.css)
```

Не является инвестиционной рекомендацией.
