# CS2 Skin Pulse

Сайт со всеми скинами CS2 и живыми ценами Steam Community Market.

- **Каталог** — все скины оружия, ножей и перчаток с группировкой по типу оружия, конкретному оружию, редкости, **коллекциям**, **кейсам** и **операциям**.
- **⚡ Быстрый топ** — скины, быстрее всего растущие в цене за 1 / 6 / 24 часа. Пересчитывается **каждые 30 минут**.
- **📈 Долгий холд** — скины с наибольшим ростом за 30 / 7 / 90 дней. Пересчитывается **раз в сутки**.
- Страница скина — цены всех вариантов (износ, StatTrak™, Souvenir), изменение за 24ч/7д/30д, график и ссылка на Steam.

## Как это работает

```
GitHub Actions (cron */30) ──► scripts/update.mjs ──► Steam Market (search/render, USD)
        │                             │
        │                     ветка `data` — состояние: цены, история (30 ч по 30 мин + до 400 дней)
        ▼
GitHub Pages ◄── site/ (HTML/CSS/JS) + site/data/*.json
```

- Каталог скинов: [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API), обновляется раз в сутки.
- Цены: минимальный лот на Steam Market (`sell_price`) и число лотов на продаже.
- Чтобы топы не забивал шум неликвида, в рейтинг попадают только позиции с ценой от $0.20 (быстрый) / $1 (холд) и минимум 5 лотами.
- Привязка коллекций к операциям — в `scripts/operations.json`, её можно править руками.

## Запуск локально

```bash
node scripts/update.mjs --daily     # собрать каталог
node scripts/update.mjs             # опросить Steam и посчитать быстрый топ
npx serve site                      # открыть сайт
```

Для отладки без Steam: `MOCK=1 node scripts/update.mjs`.

## Ограничения

- Steam ограничивает частоту запросов; полный проход (~200 страниц) занимает 10–15 минут. Если Steam отвечает 429, прогон продолжится со следующего места в следующий раз.
- Топ «долгий холд» становится честным после месяца сбора истории; до этого берётся самый ранний доступный день.
- GitHub отключает расписание в репозиториях без активности 60 дней — если это случится, включите workflow во вкладке Actions.
- Не является инвестиционной рекомендацией.
