# CS2 Spread

Сайт, который сравнивает цены скинов CS2 в рублях на площадках, куда можно завести деньги из России, и считает выгоду перепродажи за вычетом комиссий: купить на одной площадке → продать на другой.

| Площадка | Покупка | Продажа | Комиссия продажи (по умолчанию) | Откуда цены |
|---|---|---|---|---|
| Steam | да | да, деньги остаются в кошельке Steam | 13,04% (покупатель платит +15%) | VPS (`scripts/steam-crawl.mjs`) — серверы GitHub Steam не пускает |
| Market.CSGO | да | да, с выводом | 5% | напрямую в рублях; с серверов GitHub — снимок с VPS |
| LIS-SKINS | да | нет (только выкуп по их цене, его нет в данных) | — | напрямую, в долларах; переводится по курсу Market.CSGO, но не ниже ЦБ |
| CS.MONEY | да | да, с выводом | 5% | сводка csgotrader.app за сутки, в долларах, без числа лотов (API маркета закрыт Cloudflare); курс — как у LIS-SKINS |

Переключатель **«Все площадки»** добавляет зарубежные маркеты (из России напрямую не пополнить; цены в долларах, по курсу ЦБ):

| Площадка | Комиссия продажи (по умолчанию) | Откуда цены |
|---|---|---|
| Skinport | 8% | напрямую, с числом лотов |
| Waxpeer | 6% | напрямую, с числом лотов |
| Buff163 | 2,5% | сводка csgotrader.app за сутки |
| CSFloat | 2% | сводка csgotrader.app за сутки |
| Youpin898 | 1% | сводка csgotrader.app за сутки; цены в ней в среднем на 7% выше реальных сделок, поэтому продажа туда по умолчанию выключена |

Ценовые категории: все цены, до $50, до $100, до $500 (по цене покупки).

Комиссии пополнения и вывода зависят от способа оплаты — на сайте их можно задать, как и свой курс LIS-SKINS и CS.MONEY, и выбрать, на каких площадках покупать и продавать.

## Как считается выгода

Для каждого предмета перебираются маршруты «купить на A → продать на B»:

```
затраты  = цена лота на A × (1 + пополнение A)
выручка  = цена лота на B × (1 − комиссия продажи B) × (1 − вывод B)
выгода   = выручка − затраты
```

- Площадка с числом лотов меньше 2 не учитывается.
- Маршрут, где цена продажи выше покупки больше чем в 1,8 раза, отбрасывается: почти всегда это ошибка в данных или один случайный лот.
- Цена покупки ниже 60% или продажи выше 200% от медианы реальных сделок на Skinport за 30 дней тоже отбрасывается.

## Продажи и «Лучшие»

- **Steam:** число продаж за сутки (`priceoverview`). Это запрос на каждый предмет, поэтому VPS проверяет только кандидатов — `site/data/candidates.json`, до 80 за запуск, каждый не чаще раза в 20 часов.
- **Skinport:** продажи за 7 и 30 дней сразу по всем предметам (`/v1/sales/history`). Торговать там из России нельзя, но как мера спроса годится; используется, пока нет данных Steam, с поправкой ×0,5.
- Ликвидность k = min(1, продаж в сутки / 20). Сортировка «Лучшие» = выгода в рублях × k², чтобы наверху было то, что и выгодно, и быстро продаётся.
- Ножи с фазами Doppler не сравниваются: у всех фаз одно название на рынке.
- Предмет после покупки на Steam Market или обмена обычно нельзя передать 7 дней — цена за это время может уйти.

## Устройство

```
VPS, cron */30   scripts/vps-run.sh → steam-crawl.mjs → ветка `steam` (цены Steam + снимок Market.CSGO)
GitHub Actions   .github/workflows/update.yml — раз в час проверяет, прошло ли 10 часов; если да —
                 scripts/collect.mjs → site/data → GitHub Pages
site/            статический сайт без сборки (index.html, app.js, style.css)
```

Steam без входа в аккаунт отдаёт 10 предметов за запрос, весь рынок (~35 тыс.) обходится примерно за сутки с паузами из-за ограничений Steam. С cookie `steamLoginSecure` — 100 за запрос, обход за час-два.

## Установка сборщика Steam на VPS

Нужен fine-grained токен GitHub с доступом к этому репозиторию: Contents → Read and write.

```bash
curl -fsSL https://raw.githubusercontent.com/voy1ok/cs2-skin-pulse/main/scripts/vps-setup.sh | bash
```

Лог: `tail -f /var/log/cs2spread.log`.

## Запуск локально

```bash
STATE_DIR=steam BUDGET_MIN=2 node scripts/steam-crawl.mjs   # немного цен Steam (необязательно)
node scripts/collect.mjs                                      # собрать данные в site/data
npx serve site
```

Не является инвестиционной рекомендацией.
