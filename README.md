# CS2 Skin Pulse

Сайт со всеми скинами CS2, ценами Steam Community Market и топом растущих предметов CS2.

- **Каталог** — все скины оружия, ножей и перчаток с группировкой по типу оружия, конкретному оружию, редкости, **коллекциям**, **кейсам** и **операциям**.
- **⚡ Быстрый топ** — предметы, быстрее всего растущие в цене за 1 / 6 / 24 часа: оружие, ножи, перчатки, наклейки, агенты, кейсы, граффити, музыкальные наборы, нашивки, брелоки — всё, что продаётся в CS2. Пересчитывается **каждые 5 минут** — чаще нельзя: Skinport кэширует ответ на 5 минут. Страница сама подхватывает новый топ (проверка каждые 20 секунд).
- **📈 Долгий холд** — предметы с наибольшим ростом за 30 / 7 / 90 дней. Пересчитывается **раз в сутки**.
- Страница скина — цены всех вариантов (износ, StatTrak™, Souvenir), изменение за 24ч/7д/30д, график и ссылка на Steam.

## Как это работает

```
VPS (cron */5)  ──► vps-run.sh --market ──► update.mjs --market ──► Skinport API (все предметы, быстрый топ)
VPS (cron */30) ──► vps-run.sh          ──► update.mjs          ──► Steam Market (search/render, USD, каталог)
        │
        ├─► ветка `data` — состояние: цены, история (30 ч по 30 мин + до 400 дней)
        └─► repository_dispatch ──► GitHub Actions ──► GitHub Pages (site/ + data/*.json)
```

- Каталог скинов: [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API), обновляется раз в сутки.
- Топы: [Skinport API](https://docs.skinport.com/items) — один запрос отдаёт все ~25 тыс. предметов CS2 с минимальной ценой лота и числом лотов. В Steam столько же предметов (~35 тыс.) без логина отдаются по 10 за запрос, полный проход занимает часы, поэтому для топов он не годится. Цены в топах — цены Skinport, а не Steam.
- Каталог: минимальный лот на Steam Market (`sell_price`) и число лотов на продаже.
- Картинки и типы предметов вне скинов (наклейки, агенты, кейсы…) — из того же ByMykel/CSGO-API.
- Чтобы топы не забивал шум неликвида, в рейтинг попадают только позиции с ценой от $0.20 (быстрый) / $1 (холд) и минимум 5 лотами.
- Привязка коллекций к операциям — в `scripts/operations.json`, её можно править руками.

## Установка сборщика на VPS

Steam блокирует серверы GitHub Actions (HTTP 429), поэтому цены собирает свой VPS.
Нужен fine-grained токен GitHub с доступом к этому репозиторию: Contents → Read and write.

```bash
curl -fsSL https://raw.githubusercontent.com/voy1ok/cs2-skin-pulse/main/scripts/vps-setup.sh | bash
```

Лог: `tail -f /var/log/skinpulse.log`. Расписание — `scripts/skinpulse.cron`, `vps-run.sh` сам копирует его в `/etc/cron.d/skinpulse`.

## Запуск локально

```bash
node scripts/update.mjs --daily     # собрать каталог
node scripts/update.mjs --market    # снимок цен Skinport и быстрый топ
node scripts/update.mjs             # опросить Steam (цены каталога)
node scripts/update.mjs --render    # собрать данные сайта в site/data
npx serve site                      # открыть сайт
```

Для отладки без Steam: `MOCK=1 node scripts/update.mjs`.

## Ограничения

- Steam ограничивает частоту запросов; полный проход по скинам (~1 600 страниц по 10 позиций) занимает часы. Если Steam отвечает 429, прогон продолжится со следующего места в следующий раз. На топы это не влияет.
- Skinport отвечает только клиентам с поддержкой Brotli (`Accept-Encoding: br`); Node 18+ это умеет.
- Топ «долгий холд» становится честным после месяца сбора истории; до этого берётся самый ранний доступный день.
- GitHub отключает расписание в репозиториях без активности 60 дней — если это случится, включите workflow во вкладке Actions.
- Не является инвестиционной рекомендацией.
